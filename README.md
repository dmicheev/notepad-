# notepad+

# BLAZING FAST MULTIFORMATS TEXT EDITOR

Нативный редактор кода и текста на Rust + GPUI для macOS (Apple Silicon). Открывает мгновенно файлы любого размера — подсветка идёт прогрессивно, кадровый бюджет держит интерфейс отзывчивым даже на файлах в десятки мегабайт.

## Возможности

- **Редактор**: мульти-курсор, column selection, undo/redo через транзакции, rope-документ (ropey)
- **Подсветка синтаксиса**: 60+ грамматик syntect (Rust, JSON, Python, Markdown, YAML…), прогрессивная раскраска с чекпоинтами и бюджетом на кадр
- **CSV/TSV**: чередование цветов колонок, липкая строка заголовков, настройка разделителя и квотирования (диалог при открытии + переключатель в статус-баре), выбор сохраняется в `.settings/workspace.toml`
- **Форматы файлов**: детект кодировки (encoding_rs + chardetng), переводы строк, файлы свыше 20 МБ — с вопросом о включении подсветки
- **Навигация**: переход к строке, закладки, свёртывание блоков, поиск в файле/вкладках/папке с заменой
- **Операции со строками**: сортировка, дедупликация, удаление пустых, смена регистра
- **Markdown**: предпросмотр-панель (pulldown-cmark)
- **Инструменты**: форматирование/minify JSON, split view (до 4 панелей), синхронный скролл
- **Рабочее место**: дерево воркспейса с FS-наблюдателем, сессия (вкладки/геометрия/тема восстанавливаются), настройки папки в `.settings/workspace.toml`
- **Интерфейс**: тёмная/светлая темы (VS Code-палитры), выбор шрифта, локализация (en + внешние TOML-файлы без пересборки), панель производительности

## Сборка

Требуется Rust 1.85+ (edition 2024).

### Быстрая отладочная сборка

```sh
make            # или: make debug
```

### Релиз (максимальная оптимизация)

```sh
make release
```

Собирает с `target-cpu=native` + fat LTO + `codegen-units=1` и кладёт в `bin/`:
- `bin/notepad-plus` — сырой бинарь
- `bin/notepad-plus.app` — бандл для запуска из Finder (без терминального окна) и регистрации в LaunchServices

### Запуск без Make

```sh
cargo build                          # debug
cargo run                            # запустить dev-сборку
RUSTFLAGS="-C target-cpu=native" \
CARGO_PROFILE_RELEASE_LTO=fat \
CARGO_PROFILE_RELEASE_CODEGEN_UNITS=1 \
cargo build --release                # релиз
```

## Тесты

```sh
make test        # все тесты воркспейса
cargo test       # то же самое
cargo test -p editor-core          # только ядро (rope/подсветка/транзакции)
cargo test -p app --bin notepad-plus csv   # GUI-тесты по подстроке
```

## Структура проекта

```
crates/
  app/           — GPUI-приложение: окна, вкладки, панели, диалоги, статус-бар
  editor-core/   — ядро без GPUI: Document (rope), History/undo, транзакции,
                   детект кодировки, движок подсветки, поиск
  markdown/      — парсер Markdown (блоки/инлайны)
  i18n/          — переводы UI (вшитый en.toml + внешние файлы языков)
openspec/        — спеки и изменения (OpenSpec-процесс)
packaging/       — Info.plist для .app-бандла
```

## Очистка

```sh
make clean       # cargo clean + bin/
```
