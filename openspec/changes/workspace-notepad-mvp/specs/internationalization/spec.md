# Spec Delta

## Purpose

Локализация интерфейса: все строки UI хранятся во внешних файлах переводов, один файл на язык; новые языки добавляются без пересборки приложения.

## ADDED Requirements

### Requirement: Внешние файлы переводов
Приложение SHALL хранить все строки интерфейса (меню, диалоги, подписи, сообщения) во внешних файлах переводов — один файл на язык — и загружать их при старте. В MVP поставляется английский язык.

#### Scenario: Строки не захардкожены
- **WHEN** разработчик добавляет новый элемент UI
- **THEN** его подпись задаётся ключом в файле переводов, а не строкой в коде

### Requirement: Выбор языка без пересборки
Приложение SHALL позволять добавить новый язык, поместив файл переводов в каталог переводов и выбрав язык в настройках. Пересборка или изменение кода приложения для этого не требуются.

#### Scenario: Добавление русского языка
- **WHEN** пользователь кладёт файл `ru.json` (или `ru.toml`) в каталог переводов и выбирает русский в настройках
- **THEN** интерфейс отображается на русском; отсутствующие ключи показываются на английском (fallback)
