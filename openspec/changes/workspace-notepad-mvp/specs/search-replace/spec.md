# Spec Delta

## Purpose

Поиск и замена текста: в текущем файле, по всем открытым вкладкам и по файлам в папке (воркспейса), с поддержкой регулярных выражений.

## ADDED Requirements

### Requirement: Поиск и замена в файле
Приложение SHALL искать текст в текущем файле (вперёд/назад, с подсветкой всех совпадений) и заменять его по одному вхождению или во всём файле. Режимы: обычный текст, регулярные выражения, учёт регистра, целые слова.

#### Scenario: Поиск по регулярному выражению
- **WHEN** пользователь включает режим regex и ищет `\d{4}-\d{2}-\d{2}`
- **THEN** подсвечиваются все даты вида YYYY-MM-DD, доступна навигация по совпадениям

#### Scenario: Замена с группами захвата
- **WHEN** пользователь в режиме regex заменяет `(\w+)@example\.com` на `<$1>`
- **THEN** каждое совпадение заменяется с подстановкой группы захвата

### Requirement: Поиск по всем открытым вкладкам
Приложение SHALL искать текст по содержимому всех открытых вкладок и показывать результаты списком (файл, строка, фрагмент) с переходом к совпадению по клику.

#### Scenario: Поиск по вкладкам
- **WHEN** пользователь открывает панель «Найти во вкладках» и вводит запрос
- **THEN** отображается список совпадений по каждой вкладке; клик по результату активирует вкладку и позицию совпадения

### Requirement: Поиск по файлам в папке
Приложение SHALL искать текст по файлам в выбранной папке (по умолчанию — воркспейс), включая подпапки, с фильтрацией по маске файлов, и показывать результаты списком с переходом к совпадению.

#### Scenario: Поиск в воркспейсе
- **WHEN** пользователь запускает «Найти в файлах» с запросом по воркспейсу
- **THEN** результаты сгруппированы по файлам с указанием номера строки и фрагмента; клик открывает файл на нужной позиции

#### Scenario: Замена по файлам
- **WHEN** пользователь запускает «Заменить в файлах» с подтверждением
- **THEN** все совпадения во всех затронутых файлах заменяются, затронутые файлы открываются во вкладках как изменённые (сохранение остаётся за пользователем)
