# Spec Delta

## Purpose

Продвинутые операции редактирования текста: преобразования над строками и многострочное редактирование (column selection / multi-cursor).

## ADDED Requirements

### Requirement: Сортировка строк
Приложение SHALL сортировать выделенные строки (или весь файл, если ничего не выделено) по возрастанию, по убыванию и с учётом/без учёта регистра.

#### Scenario: Сортировка выделения
- **WHEN** пользователь выделяет строки в произвольном порядке и вызывает «Сортировать по возрастанию»
- **THEN** выделенные строки перестраиваются в лексикографическом порядке, остальной текст не меняется

### Requirement: Удаление дубликатов и пустых строк
Приложение SHALL удалять повторяющиеся строки и/или пустые строки в выделении или во всём файле.

#### Scenario: Удаление дубликатов
- **WHEN** пользователь вызывает «Удалить дубликаты» на выделении с повторяющимися строками
- **THEN** остаётся ровно по одному экземпляру каждой уникальной строки, порядок первых вхождений сохраняется

### Requirement: Преобразование регистра
Приложение SHALL преобразовывать регистр выделенного текста: ВЕРХНИЙ, нижний, Заголовочный (Title Case), Sentence case.

#### Scenario: Верхний регистр
- **WHEN** пользователь выделяет текст и вызывает «В ВЕРХНИЙ РЕГИСТР»
- **THEN** все буквы выделения становятся заглавными, длина и остальной текст не меняются

### Requirement: Многострочное редактирование
Приложение SHALL поддерживать column selection (прямоугольное выделение) и multi-cursor: несколько курсоров, вставка курсора по Ctrl/Cmd+клику и по совпадению слова, одновременное редактирование во всех позициях.

#### Scenario: Column selection
- **WHEN** пользователь выделяет прямоугольный блок с зажатым Alt/Cmd
- **THEN** в начале каждой строки блока появляется отдельный курсор, и ввод текста применяется во всех позициях одновременно

#### Scenario: Курсор по совпадениям слова
- **WHEN** пользователь вызывает «Добавить следующий курсор на совпадение» (двойной Ctrl/Cmd+D)
- **THEN** к текущему выделению добавляется следующее вхождение этого слова с собственным курсором
