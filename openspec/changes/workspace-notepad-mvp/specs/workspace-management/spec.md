# Spec Delta

## Purpose

Воркспейс — корневая папка-проект, объединяющая заметки пользователя: дерево проекта с подпапками в стиле Project view IntelliJ IDEA и запоминание последнего воркспейса между сессиями.

## ADDED Requirements

### Requirement: Открытие воркспейса
Приложение SHALL позволять пользователю выбрать папку на диске и открыть её как воркспейс. Содержимое воркспейса SHALL отображаться в панели «Проект» в виде дерева файлов и папок.

#### Scenario: Пользователь открывает папку как воркспейс
- **WHEN** пользователь выбирает «Открыть воркспейс» и указывает папку
- **THEN** панель «Проект» показывает дерево файлов и подпапок этой папки

### Requirement: Организация подпапок
Приложение SHALL позволять создавать, переименовывать, удалять и перемещать подпапки и файлы внутри дерева проекта, включая вложенность произвольной глубины.

#### Scenario: Создание подпапки
- **WHEN** пользователь вызывает «Новая папка» на узле дерева и вводит имя
- **THEN** подпапка создаётся на диске и появляется в дереве

#### Scenario: Перемещение файла в дереве
- **WHEN** пользователь перетаскивает файл на другую папку дерева
- **THEN** файл перемещается на диске, открытые вкладки этого файла остаются привязанными к новому пути

### Requirement: Синхронизация дерева с диском
Приложение SHALL отражать в дереве проекта изменения файловой системы, сделанные вне приложения (создание, удаление, переименование файлов и папок воркспейса).

#### Scenario: Файл создан извне
- **WHEN** пользователь создаёт файл в папке воркспейса через стороннюю программу
- **THEN** файл появляется в дереве проекта без перезапуска приложения

### Requirement: Запоминание воркспейса
Приложение SHALL сохранять путь последнего открытого воркспейса и восстанавливать его при следующем запуске.

#### Scenario: Перезапуск приложения
- **WHEN** пользователь закрывает и снова запускает приложение
- **THEN** последний воркспейс открывается автоматически
