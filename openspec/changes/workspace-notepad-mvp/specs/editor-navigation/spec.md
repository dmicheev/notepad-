# Spec Delta

## Purpose

Навигация по документу: закладки на строках, нумерация строк, свёртывание блоков.

## ADDED Requirements

### Requirement: Закладки на строках
Приложение SHALL позволять ставить/снимать закладки на строках, перемещаться между закладками (следующая/предыдущая) и видеть все закладки файла в панели закладок.

#### Scenario: Постановка закладки
- **WHEN** пользователь наживает Ctrl/Cmd+F2 на строке
- **THEN** на полях строки появляется маркер закладки

#### Scenario: Навигация по закладкам
- **WHEN** пользователь нажимает F2
- **THEN** курсор переходит к следующей закладке файла (по кругу)

### Requirement: Нумерация строк
Приложение SHALL отображать нумерацию строк на полях редактора и подсвечивать номер текущей строки. Приложение SHALL поддерживать переход к строке по номеру (Ctrl/Cmd+G).

#### Scenario: Переход к строке
- **WHEN** пользователь вводит «42» в диалоге перехода к строке
- **THEN** курсор перемещается на строку 42, и она становится видимой в области просмотра

### Requirement: Свёртывание блоков
Приложение SHALL определять логические блоки (функции, секции, блоки по отступам) в файлах с распознанным синтаксисом и позволять свёртывать/разворачивать их по отдельности и целиком.

#### Scenario: Свёртывание функции
- **WHEN** пользователь нажимает маркер свёртывания у начала функции
- **THEN** тело функции скрывается, на полях остаётся компактный индикатор; при разворачивании текст восстанавливается полностью
