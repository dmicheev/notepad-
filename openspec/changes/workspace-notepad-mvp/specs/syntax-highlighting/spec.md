# Spec Delta

## Purpose

Автоопределение языка файла и подсветка синтаксиса для широкого набора языков (цель — 70+, как в Notepad++).

## ADDED Requirements

### Requirement: Автоопределение языка
Приложение SHALL автоматически определять язык файла по расширению, а при неоднозначности — по содержимому, и применять соответствующую подсветку. Пользователь SHALL иметь возможность вручную выбрать язык из списка.

#### Scenario: Открытие Python-файла
- **WHEN** пользователь открывает файл `script.py`
- **THEN** включается подсветка синтаксиса Python без действий пользователя

#### Scenario: Ручной выбор языка
- **WHEN** пользователь выбирает язык YAML для файла без расширения
- **THEN** подсветка YAML применяется немедленно

### Requirement: Набор поддерживаемых языков
Приложение SHALL поддерживать подсветку не менее 70 распространённых языков программирования, скриптовых языков и форматов разметки (включая как минимум: C/C++, C#, Go, Java, JavaScript, TypeScript, Python, Rust, SQL, HTML, XML, JSON, YAML, Markdown, Shell, CSS).

#### Scenario: Проверка покрытия форматов
- **WHEN** пользователь открывает файлы `.go`, `.ts`, `.json`, `.md`, `.sh`
- **THEN** каждый файл получает корректную подсветку своего формата

### Requirement: Подсветка активна на больших файлах
Приложение SHALL сохранять отзывчивость редактора при подсветке файлов не менее 20 МБ (ввод и прокрутка без заметных задержек). Для файлов свыше 20 МБ приложение SHALL автоматически отключать подсветку, уведомив пользователя.

#### Scenario: Открытие большого лога
- **WHEN** пользователь открывает файл 20 МБ с подсветкой
- **THEN** приложение остаётся отзывчивым, ввод и прокрутка не блокируются

#### Scenario: Файл сверх порога
- **WHEN** пользователь открывает файл больше 20 МБ
- **THEN** подсветка автоматически отключается, приложение сообщает об этом, редактирование доступно
