# Spec Delta

## Purpose

Открытие файлов: вкладки как представления открытых файлов, работа как с файлами воркспейса, так и с произвольными файлами файловой системы, восстановление сессии вкладок.

## ADDED Requirements

### Requirement: Вкладки для файлов
Приложение SHALL открывать каждый файл в отдельной вкладке и позволять переключаться между вкладками, закрывать их и менять порядок. Вкладки SHALL показывать имя файла и индикатор несохранённых изменений.

#### Scenario: Открытие нескольких файлов
- **WHEN** пользователь открывает три файла подряд
- **THEN** создаются три вкладки, активная — последняя открытая

#### Scenario: Индикатор изменений
- **WHEN** пользователь изменяет текст в открытой вкладке
- **THEN** на вкладке появляется индикатор несохранённых изменений, исчезающий после сохранения

### Requirement: Открытие файлов вне воркспейса
Приложение SHALL позволять открывать отдельные файлы из любого места файловой системы, независимо от того, находится ли файл внутри текущего воркспейса. Такие файлы SHALL отображаться во вкладках так же, как файлы воркспейса.

#### Scenario: Файл вне воркспейса
- **WHEN** пользователь открывает файл вне папки воркспейса
- **THEN** файл открывается во вкладке, а дерево проекта не меняется

### Requirement: Восстановление сессии
Приложение SHALL сохранять список открытых вкладок и активную вкладку при закрытии и восстанавливать их при следующем запуске. Вкладки, чьи файлы были удалены извне, SHALL не восстанавливаться молча-ошибочно: приложение показывает это явно.

#### Scenario: Восстановление вкладок
- **WHEN** пользователь закрывает приложение с тремя открытыми вкладками и запускает снова
- **THEN** те же три вкладки открыты, активна та же вкладка, что была при закрытии

#### Scenario: Файл вкладки удалён извне
- **WHEN** при восстановлении сессии файл одной из вкладок не существует
- **THEN** вкладка не открывается, приложение сообщает о пропущенном файле, остальные вкладки открываются
