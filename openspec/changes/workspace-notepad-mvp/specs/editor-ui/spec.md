# Spec Delta

## Purpose

Пользовательский интерфейс редактора: разделённый экран с синхронной прокруткой, темы, настройка шрифтов, горячие клавиши.

## ADDED Requirements

### Requirement: Разделённый экран
Приложение SHALL позволять разделить область редактора на 2 (и до 4) панелей, отображающих разные файлы (или один файл) одновременно, с опциональной синхронной прокруткой между панелями.

#### Scenario: Синхронная прокрутка
- **WHEN** пользователь включает split view для двух файлов и активирует синхронную прокрутку
- **THEN** прокрутка одной панели синхронно прокручивает вторую

### Requirement: Темы
Приложение SHALL предоставлять тёмную и светлую темы, по умолчанию следуя системной настройке, и позволять переключаться вручную. Выбор сохраняется между сессиями.

#### Scenario: Переключение темы
- **WHEN** пользователь переключает тему на тёмную
- **THEN** весь интерфейс (редактор, панели, деревья) перерисовывается в тёмной теме, выбор сохраняется после перезапуска

### Requirement: Настройка шрифтов
Приложение SHALL позволять настраивать семейство и размер шрифта редактора; настройка сохраняется между сессиями.

#### Scenario: Увеличение шрифта
- **WHEN** пользователь увеличивает размер шрифта в настройках
- **THEN** текст в редакторе перерисовывается крупнее немедленно, настройка сохраняется

### Requirement: Горячие клавиши
Приложение SHALL назначать горячие клавиши всем ключевым действиям (открыть/сохранить, поиск/замена, вкладки, закладки, split view, переключение языка) и позволять просматривать их в справочнике. Стандартные сочетания (Ctrl/Cmd+S, Ctrl/Cmd+F и т.п.) SHALL соответствовать общепринятым.

#### Scenario: Сохранение с клавиатуры
- **WHEN** пользователь нажимает Ctrl/Cmd+S
- **THEN** активный файл сохраняется без открытия диалогов

#### Scenario: Справочник сочетаний
- **WHEN** пользователь открывает раздел горячих клавиш
- **THEN** отображается полный список действий с назначенными сочетаниями

### Requirement: Локализация интерфейса
Приложение SHALL хранить все строки интерфейса во внешних файлах переводов (один файл на язык) и загружать их при старте. MVP поставляется с английским языком; добавление нового языка SHALL не требовать изменения кода приложения.

#### Scenario: Добавление перевода
- **WHEN** в каталог переводов добавляется файл нового языка и язык выбирается в настройках
- **THEN** интерфейс отображается на этом языке без пересборки приложения
