# Spec Delta

## Purpose

Корректная работа с текстовыми форматами: определение и конвертация кодировок, переводы строк LF/CRLF/CR с конвертацией на лету.

## ADDED Requirements

### Requirement: Определение кодировки
Приложение SHALL автоматически определять кодировку открываемого файла (UTF-8, UTF-8 BOM, UTF-16/UCS-2, ASCII-совместимые однобайтовые кодировки) и отображать её в статус-баре. Пользователь SHALL иметь возможность переоткрыть файл в явно указанной кодировке, если автоопределение ошибочно.

#### Scenario: Открытие файла в UTF-8
- **WHEN** пользователь открывает корректный UTF-8 файл
- **THEN** текст отображается без артефактов, статус-бар показывает UTF-8

#### Scenario: Переоткрытие в другой кодировке
- **WHEN** пользователь выбирает «Переоткрыть в кодировке Windows-1251»
- **THEN** файл перечитывается с диска в указанной кодировке без сохранения текущего текста

### Requirement: Конвертация кодировки
Приложение SHALL позволять конвертировать файл в другую кодировку (включая UTF-8, UTF-8 BOM, UTF-16) с сохранением.

#### Scenario: Сохранение в другой кодировке
- **WHEN** пользователь выбирает «Преобразовать в UTF-8» и сохраняет файл
- **THEN** файл на диске перезаписывается в UTF-8, статус-бар обновляется

### Requirement: Переводы строк
Приложение SHALL определять формат переводов строк файла (LF, CRLF, CR), отображать его в статус-баре и позволять конвертировать формат на лету без перезагрузки файла.

#### Scenario: Конвертация CRLF в LF
- **WHEN** пользователь выбирает LF в меню формата строк файла с CRLF
- **THEN** все переводы строк в буфере конвертируются в LF, статус-бар показывает LF, несохранённое изменение помечается

#### Scenario: Сохранение с согласованными переводами строк
- **WHEN** пользователь сохраняет файл после конвертации
- **THEN** на диске файл записан с выбранным форматом переводов строк
