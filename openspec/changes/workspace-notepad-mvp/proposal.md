# Proposal

## Why

Популярные лёгкие редакторы (Notepad++) привязаны к Windows, а современные IDE избыточны для быстрой работы с заметками и текстовыми файлами. Нужен быстрый кроссплатформенный блокнот, объединяющий модель «воркспейс-проекта заметок» (как в IDE) с лёгкостью классического notepad.

## What Changes

- Новый проект (greenfield): десктопный редактор текста/заметок.
- Модель воркспейса: папка-проект с деревом заметок и подпапок (как Project view в IntelliJ IDEA).
- Табулированный редактор: вкладки = файлы воркспейса; при этом можно открывать отдельные файлы из любого места ФС вне воркспейса.
- Полноценный текстовый редактор: поиск/замена с regex, поиск по вкладкам и по файлам папки, операции со строками, закладки, нумерация строк, свёртывание блоков, многострочное (column/multi-cursor) редактирование.
- Работа с форматами файлов: определение и конвертация кодировок, переводы строк LF/CRLF/CR на лету.
- Автоопределение языка и подсветка синтаксиса для широкого набора языков (~как в Notepad++, 70+).
- UI: разделённый экран с синхронной прокруткой, тёмная/светлая темы, настройка шрифтов, горячие клавиши на все основные действия.

## Capabilities

### New Capabilities
- `workspace-management`: воркспейс как папка-проект заметок; дерево проекта с подпапками (создание/переименование/удаление/перемещение); запоминание последнего воркспейса.
- `file-opening`: открытие отдельных файлов из любого места ФС в дополнение к воркспейсу; вкладки как представления открытых файлов; состояние сессии (открытые вкладки) восстанавливается.
- `text-editing`: операции со строками (сортировка, удаление дублей/пустых строк, преобразование регистра), многострочное редактирование (column selection / multi-cursor).
- `search-replace`: поиск и замена с регулярными выражениями в текущем файле, по всем открытым вкладкам и по файлам в папке.
- `editor-navigation`: закладки на строках, нумерация строк, свёртывание блоков кода/секций.
- `file-formats`: определение и конвертация кодировок (UTF-8, ASCII, UCS-2 и др.); работа с переводами строк LF/CRLF/CR и конвертация на лету.
- `syntax-highlighting`: автоопределение языка по содержимому/расширению и подсветка синтаксиса для 70+ языков.
- `editor-ui`: разделённый экран (split view) с синхронной прокруткой, тёмная/светлая темы, настройка шрифтов, горячие клавиши на все ключевые действия.
- `internationalization`: строки интерфейса во внешних файлах переводов (один файл на язык); MVP — английский, новые языки добавляются без изменения кода.

## Impact

- Новый код: всё приложение с нуля (директория пуста).
- Ключевой технический выбор (движок редактора, GUI-фреймворк, платформы) — в design.md.
- Зависимости: GUI-фреймворк + компонент редактора с подсветкой (типа Scintilla/CodeMirror/Monaco/tree-sitter) — выбор при обсуждении архитектуры.
