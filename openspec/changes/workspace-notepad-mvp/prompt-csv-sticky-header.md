> поправить (см. раздел «Спека»).

## Контекст

Ты дорабатываешь notepad+ (Rust-редактор на gpui 0.2.2, crates/app +
crates/editor-core). Группа 5 готова: подсветка через syntect +
собственный CSV-режим — колонки чередуются 4 цветами (`csv_spans`,
`CLASS_COLUMN_A..D`, D12.4), порог 20 МБ спрашивает пользователя
(согласие → подсветка любого размера). Сейчас 226 тестов
(112 app + 114 editor-core) — обязаны остаться зелёными.

Запрос пользователя: «для CSV строку с названием колонок всегда
закреплять наверху и выделять рамкой» — header-строка (строка 0) при
прокрутке не должна уезжать вверх: она висит поверх списка строк,
отделённая линией/рамкой; когда файл в начале — строка 0 выделена
рамкой на своём месте.

## Задача

1. **Видимость липкой шапки**: активный язык вкладки — CSV
   (грамматика «CSV»; добавь хелпер вроде `BufferTab::is_csv()`) И
   строка 0 полностью уехала из вида (|scroll offset.y| ≥ LINE_HEIGHT)
   → над списком рендерится закреплённая строка-копия заголовка:
   - дочерний ABSOLUTE div контейнера редактора (вне uniform_list),
     top 0, на всю ширину, высота LINE_HEIGHT;
   - структура как у обычной строки: гуттер (номер 1) + текстовая
     ячейка с ЦВЕТАМИ КОЛОНОК (split_line_styled + спаны строки 0;
     `ensure_window(0..1)` перед этим — CSV stateless, дёшево);
   - сплошной фон (иначе просвечивает текст под ним), РАМКА/
     разделительная линия снизу (border_b_1), клик — прокрутка к
     началу (`scroll_to_item(0, …)` + notify).
2. **Выделение на месте**: когда заголовок видим обычным образом
   (начало файла), строка 0 в списке получает фон-подсветку шапки +
   нижнюю разделительную линию — КООРДИНАТНО НЕ меняя высоту строки
   (см. ловушки).
3. **Спека**: поправь openspec/changes/workspace-notepad-mvp/specs/
   syntax-highlighting/spec.md — расширить сценарий «Открытие
   CSV-файла» (или добавить новый): заголовок закреплён наверху при
   прокрутке, выделен рамкой. design.md — новый подраздел D12.5
   (решения/замеры). tasks.md — добавь и отметь 5.7.

## Ловушки (проверено/подозрительно — читать обязательно)

- **uniform_list требует РОВНО lineHeight на строку**: border на
  строке списка ломает разметку — выделение шапки «на месте» делай
  фоном + абсолютным 1px-дивом (absolute не влияет на layout),
  РАМКУ носит только оверлей вне списка.
- **Перерисовка при скролле**: оверлей живёт в Workspace::render —
  проверь СПИКОМ, что колесо мыши перезапускает render
  (в interactivity gpui 0.2.2 прокрутка зовёт window.refresh() —
  проверь путь ScrollWheelEvent → refresh для uniform_list; если
  нет — fallback: подписка/чтение offset на paint-фазе). Это главный
  риск задачи — не пропускай проверку.
- Оверлей перекрывает первую видимую строку — это НОРМАЛЬНО (липкая
  шапка), но клики по ней должны работать (id + on_mouse_down +
  stop_propagation, паттерн зон гуттера).
- Частично показанная строка 0 (0 < |offset| < LINE_HEIGHT): шапку
  НЕ дублируй (дубль поверх половинки — мерцание).
- Фолды: строка 0 всегда видима (скрываются только тела), но мапа
  visible→real при активных фолдах не тождественна — шапка рендерит
  REAL-строку 0, не видимую с индексом 0.
- CSV с отключённой подсветкой (>20 МБ, отказ пользователя): реши,
  липнет ли шапка без цветов (зафиксируй в D12.5; рекомендация —
  липнет, но без спанов).
- Хвост: пустой CSV/однострочный — шапка не рисуется поверх самой
  себя (guard по offset уже покрывает однострочный случай).
