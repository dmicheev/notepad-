# Proposal

## Why

Блокнот уже умеет подсвечивать Markdown как код, но для заметок этого мало: пользователь пишет заметки на Markdown и хочет видеть результат сразу — отрендеренный вид рядом с редактором (как предпросмотр в VS Code / Typora), без сохранения и внешних инструментов. Парсер markdown становится первым «формат-специфичным» режимом просмотра после CSV-подсветки — задел для будущих режимов (outline, просмотр HTML).

## What Changes

- Новый режим **Предпросмотр Markdown**: панель рядом с областью редактора, рендерит активную Markdown-вкладку (`.md`, `.markdown`).
- Тумблер: меню View → «Markdown Preview» + `Cmd/Ctrl+Shift+V`; предпросмотр следует за активной Markdown-вкладкой (в т.ч. между панелями split view).
- Живое обновление: правки в редакторе отражаются в предпросмотре без сохранения на диск (debounce, без блокировки ввода).
- Рендер CommonMark + GFM-расширения: заголовки, абзацы, жирный/курсив/зачёркнутый, инлайн-код, код-блоки (с подсветкой языка через существующий syntect-движок), списки (вложенные, чек-боксы), цитаты, ссылки (клик — открыть в браузере ОС), таблицы, горизонтальные линии.
- Изображения в MVP — плейсхолдером с alt-текстом (реальный рендер картинок — follow-up).
- Предпросмотр использует активную тему (тёмная/светлая) и переключается вместе с ней.
- Новая зависимость: `pulldown-cmark` (парсер); новый крейт `crates/markdown` (чистая модель документа, без GUI — паттерн как у `i18n`).

## Capabilities

### New Capabilities
- `markdown-preview`: живой предпросмотр Markdown-вкладок: открытие/закрытие панели, следование за активной вкладкой, рендер конструкций CommonMark/GFM, обновление при правках без сохранения, темы, поведение для не-Markdown вкладок и изображений.

## Impact

- Новый код: крейт `crates/markdown` (модель + парсер), модуль `app/src/markdown_preview.rs` (gpui-рендер), точечные правки в `workspace.rs` (состояние/раскладка), `actions.rs`/`keymap.rs`/`menus.rs` (действие и клавиша), `i18n` (новые ключи), `editor-core/document.rs` (счётчик ревизий для memo-обновления).
- Не ломает существующее: предпросмотр по умолчанию выключен; раскладка панелей не меняется, пока тумблер не включён.
- Спецификация языка: CommonMark 0.31.x + расширения GFM (таблицы, зачёркивание, чек-листы) — насколько их поддерживает выбранный парсер; нераспознанные конструкции показываются как текст.
