# Spec Delta

## Purpose

Справочник сочетаний клавиш — заметный и ищемый: центрированное модальное окно с поиском, открывается кнопкой «?» тулбара, `Cmd/Ctrl+/` и Help-меню.

## ADDED Requirements

### Requirement: Окно справочника сочетаний
Справочник сочетаний клавиш SHALL открываться как центрированное модальное окно с затемнённой подложкой: кнопкой «?» в тулбаре (capability `toolbar`), сочетанием `Cmd/Ctrl+/` и пунктом Help-меню. Окно SHALL содержать поле поиска, фильтрующее список по названию действия (на языке интерфейса) и по клавише; при пустом результате отображается сообщение об отсутствии совпадений. Esc и клик по подложке закрывают окно, фокус возвращается предыдущему владельцу.

#### Scenario: Открытие кнопкой
- **WHEN** пользователь кликает кнопку «?» в тулбаре
- **THEN** открывается центрированное модальное окно со списком всех действий и сочетаний по секциям

#### Scenario: Поиск по клавише
- **WHEN** в поле поиска введено «save»
- **THEN** список показывает только действия, содержащие «save» в названии или клавише (например, Save — Ctrl/Cmd+S)

#### Scenario: Закрытие с клавиатуры
- **WHEN** окно открыто и в фокусе, пользователь нажимает Esc
- **THEN** окно закрывается, фокус возвращается редактору
