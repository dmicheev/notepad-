# Proposal

## Why

Все 36 действий приложения спрятаны в нативном меню и на горячих клавишах — с мышкой работать нечем, а функции неочевидны (пользователь: «как переключиться в превью маркдаун не понятно»). Нужна видимая панель инструментов с кнопками под весь функционал и заметное окно подсказок по горячим клавишам (сейчас справочник есть — `Cmd+/` — но о нём не узнать, пока не откроешь Help-меню).

## What Changes

- **Тулбар**: полоса кнопок во всю ширину сверху окна (над панелью проекта и tab bar), видна по умолчанию.
  - Кнопки-действия группами: Файл (New, Open, Save), Правка (Undo, Redo), Поиск (Find, в вкладках, в папке), Навигация (Go to Line, закладки: поставить/вперёд/назад), Вид (Split, Close Pane, Sync Scroll, Markdown Preview).
  - Выпадающие кнопки для мульти-вариантных групп: Текст (10 операций со строками/регистром), Тема (System/Dark/Light).
  - Кнопка «?» — окно подсказок.
  - Каждая кнопка: SVG-иконка + всплывающая подсказка (название + сочетание клавиш, локализовано).
  - Toggle-кнопки (Sync Scroll, Markdown Preview, активная тема) показывают нажатое состояние.
  - Переключатель View → «Toolbar» прячет/показывает тулбар, состояние сохраняется в сессии.
- **Иконки**: встроенный набор монохромных SVG (~25 шт., подмножество Lucide, MIT), красятся цветом темы; подключение через `Application::with_assets` (в приложении пока нет asset-ов).
- **Окно подсказок** (улучшение существующего `Cmd+/`-оверлея): центрированное модальное окно, поле поиска-фильтра по названию действия и клавише; открывается кнопкой «?» и `Cmd+/`.
- Кнопка Markdown Preview зависит от change `markdown-preview` (ещё не применён) — применяется после него.

## Capabilities

### New Capabilities
- `toolbar`: панель кнопок над всем функционалом: состав групп, действия кнопок, тултипы, выпадающие группы, toggle-состояния, переполнение на узких окнах, иконки в темах, переключатель видимости с сохранением в сессии.

### Modified Capabilities
- `editor-ui` (delta): + окно справочника сочетаний как центрированное модальное окно с поиском (сейчас — оверлей в правом верхнем углу без поиска).

## Impact

- Новый код: `app/src/toolbar.rs` (кнопки, группы, dropdown, tooltips), `app/src/icons.rs` (AssetSource + встраиваемые SVG), переработка `keymap.rs::render_shortcuts_overlay` (модал + поиск).
- Точечные правки: `main.rs` (with_assets), `workspace.rs` (полоса в layout, `toolbar_visible`), `menus.rs` (пункт View → Toolbar), `session.rs` (persist `toolbar_visible`), i18n-ключи.
- Зависимость от change `markdown-preview`: кнопка и toggle-состояние предпросмотра активируются после его применения (в tasks помечено).
- Не ломает существующее: тулбар выключаем, все действия доступны как раньше (меню/клавиши); действия, не поместившиеся в тулбар, остаются в меню.
